ROM Rename Tool

by Codevex

Change your ROM’s name everywhere in build.prop, fingerprint included. Everything runs in your browser, so your file never leaves your phone.

1Load your build.prop

2Set the names

Spaces can break the fingerprint. Use letters, numbers, - or _ instead.

3Replace and save

Some apps check the fingerprint, Play Integrity for example. Keep your original build.prop so you can restore it if something breaks.

Using it with Termux and Debian
  1. Copy build.prop out of your system folder: cp system_out/system/build.prop /sdcard/Download/build.prop. Use the path you found with find system_out -name build.prop.
  2. Open this page, choose that file, set the names and replace.
  3. Download the new file. If your browser saves it as build (1).prop, rename it to build.prop in ZArchiver.
  4. Copy it back into Debian: cp /sdcard/Download/build.prop system_out/system/build.prop. Make a backup copy first.
